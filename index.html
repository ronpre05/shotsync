ShotSync session replay

ShotSync is a glove-mounted prototype that detects basketball shots and scores each one against the player's own reference shot. This page replays logs recorded on the device during testing: the sensor readings, the shot detector's state and the scores are exactly what the glove produced.

Source code and write-up on GitHub
